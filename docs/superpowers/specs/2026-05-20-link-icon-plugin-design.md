# 芒伊木 Wiki 名词自动 Icon 转换插件与首版排版设计规格说明

本项目基于 VitePress 构建。为提供极其现代化的 UI/UX 体验，并降低文档日常维护的复杂度，特设计本规范。

---

## 1. 核心目标
1. **书写极简化**：在 Markdown 文档中，书写 `[名词]`、`[**名词**]` 或 `**[名词]**` 时，编译器会自动将其转换为带有对应精致 Icon 和特殊色彩样式的 `<DST>` 组件。
2. **零耦合超链地基**：不直接在 Markdown 中硬编码超链接，而是通过自定义编译插件拦截名词并交由前端处理，为未来的一键无缝注入超链奠定坚实地基。
3. **首版高质感呈现**：将 `_RAW_DATA_SOURCE.md` 中的“一、 基础属性与常驻机制”内容移植并全新视觉包装至 `docs/mechanics/core.md`。

---

## 2. 详细技术方案

### 2.1 资源同步与重命名
- 在 `png/` 目录下将含空格的文件重命名：
  - `icon_mem_ beast_mode.png` ➔ `icon_mem_beast_mode.png`
  - `icon_mem_ ghost_mode.png` ➔ `icon_mem_ghost_mode.png`
- 将 `png/` 下所有 `icon_*.png`（共 31 个图标）及相关图片拷贝至 `.vitepress` 静态资源目录 `public/` 下。

### 2.2 强化自定义 Markdown-it 插件
在 `.vitepress/config.mjs` 中自定义编译期语法树解析逻辑。

#### 核心正则表达式
```javascript
const regex = /(?:\*\*)?\[(\*?\*?)([^\]]+?)\1\](?:\*\*)?(?!\()/g;
```

#### 解析与转换机制
当在 Markdown 中匹配到该正则时：
1. 提取组 2 匹配到的纯文本 `[名词]`。
2. 对名词进行前后空格及格式清理。
3. 根据核心名词映射表（如下）查询对应的 `icon` 简称：
   - `生命值`: `'health'`
   - `饱食度`: `'hunger'`
   - `理智值` / `精神值`: `'sanity'`
   - `灵魂值` / `灵魂池`: `'soul'`
   - `狐狸` / `兽化` / `[狐狸]（兽化）`: `'beast'`
   - `怨灵`: `'ghost'`
   - `封印项圈` / `封印项圈Lv1`: `'collar'`
   - `封印项圈Lv2`: `'collar-lv2'`
   - `封印项圈Lv3`: `'collar-lv3'`
   - `封印项圈Lv4·暗` / `暗项圈`: `'collar-lv4-an'`
   - `封印项圈Lv4·月` / `月项圈`: `'collar-lv4-yue'`
   - `芒式修补工具`: `'repair'`
   - `尸体防腐核心`: `'tomb-upgrader'`
   - `芒芒的尸体` / `尸体`: `'corpse'`
   - `暗影观察者`: `'shadow-gestalt'`
4. 若匹配成功，输出 `<DST icon="映射后的简称">名词</DST>`；若映射表未命中，则回退输出 `<DST icon="mod">名词</DST>`。
5. 保证标准的 Markdown 链接 `[文字](url)` 保持完整不受干扰。

### 2.3 升级 `<DST>` 组件与全局样式
在 `DST.vue` 中扩展以下功能：
- 完整支持所有 `icon` 映射和回退通用图标。
- 采用 Glassmorphism（毛玻璃）卡片包边，字体配置 DST 经典的 HSL 炫彩发光效果。
- 增加 Hover 轻微位移与亮化微动效。

### 2.4 重构一号板块 `docs/mechanics/core.md`
- 将 `_RAW_DATA_SOURCE.md` 中“一、 基础属性与常驻机制”内容移植过来。
- 将所有涉及核心机制的词汇以 `[名词]`、`[**名词**]` 规范化包裹。
- 引入现代化的卡片视图对三维属性、已死之人复活惩罚、三形态变化进行可视化重构，拒绝冗长单一的纯文字段落，呈现超流线感的海报化效果。

---

## 3. 验证方案
- **本地编译验证**：运行 `npm run dev`，检查有无解析错误。
- **页面效果检查**：
  - 检查 `[生命值]` 是否正确带有红心 icon。
  - 检查不认识的名词如 `[再一次的机会]` 是否正确带有 `icon_mod.png` 模组通用 icon。
  - 检查标准的 Markdown 链接 `[VitePress](https://...)` 是否依然正常点击，不受自动 icon 转换插件的干扰。
