# 设计规格：角色核心机制排版结构优化 (方案 A - 双栏卡片网格化)

该设计规格旨在对《芒伊木》Wiki 的 `mechanics/core.md` 中两个信息最为密集、大段文字聚集的重点小节（“死亡复活惩罚”与“兽化形态”）进行排版结构重构，从而彻底消除“阅读疲劳感”，提升 Wiki 的现代美学价值和信息检索效率。

## 1. 核心目标
- **信息层级分明**：将复杂的数值变动与判定细则，划分为独立的机制卡片与横向子卡片网格。
- **视觉风格一致**：完美融入 Wiki 中已有的高级 `.item-card`、`.item-content`、`.item-sub-grid` 和 `.sub-card` 页面排版规范。
- **保留深度文案**：绝不粗暴删减带有模组特色和虚构层设定（如“黑幕槽点”与“食物豁免细节”）的文学性描述。

---

## 2. 方案 A (子网格双栏卡片化) 重构方案

### 2.1 死亡复活惩罚 重构

将原有的散落段落和普通有序列表整体封装入 `item-card` 卡片中：
- **左侧主栏 (item-content)**：介绍惩罚的共性（25%最低上限保留），并使用 `item-sub-grid` 划分为三个子卡片：
  - **复生虚弱 (sub-card)**：聚焦永久移速/攻速/减伤扣血惩罚，将“死亡回归”、“告密的心”、“暗影心房”、“附身心房”的清除和递减规则梳理为直观的无序列表。
  - **灵魂震荡 (sub-card)**：突出惩罚的距离判定、三维上限惩罚（除饱食度）和每 5 秒的自愈机制。
  - **灵魂裂痕 (sub-card, span 2)**：单栏跨度，描述灵魂值上限损失比例以及灵魂池的优先修补规则。
- **右侧侧栏 (MediaCard)**：完美并排放置 `box_3.webp`，使右上角的状态叠加受损示意图与左侧机制内容遥相呼应，产生极强的“呼吸感”。

### 2.2 兽化形态 (狐狸) 重构

将原本堆叠在一起的属性变动、穿戴代价、专属技能与技能树加成重新排布：
- **左侧主栏 (item-content)**：说明变身消耗（进 20%饱食，出 20%理智），并使用 `item-sub-grid` 细分为 4 个高度聚焦的子卡片：
  - **🦊 数值与属性强化 (sub-card)**：收纳 1.0攻击、空手伤害/距离、攻速提升、+35%移速、防水/隔热/保暖以及怪物仇恨光环。
  - **⚠️ 形态代价与局限 (sub-card)**：梳理头手装备限制（继承特例：启迪之冠、铥皇冠特效）以及食物收益减半但负面免除的特殊消化属性。
  - **🌪️ 专属主动技能 (sub-card)**：详细阐述 **跳跃 (`R`键)**、**捕猎 (`X`键)** 以及 **藏食物** 的判定条件、消耗与触发概率。
  - **🧬 技能树天赋加成 (sub-card)**：将野兽体质（空手工作/藏食物翻倍）、隐藏本能（动物中立/捕猎移速减免缓和）、精准度优化的升级变化统一展示。
- **右侧侧栏 (MediaCard)**：放置 `box_1.webp`（极限攻速对比图），实现完美图文并排。

## 4. 验证计划
1. **编译测试**：运行 `npm run docs:dev`，在本地环境以 Chrome 浏览器测试 `core.md` 的排版呈现效果。
2. **样式契合**：确保在 **白天（羊皮纸风格）** 与 **黑夜（暗影发光风格）** 双重主题下，卡片文字的对比度、间距及发光效果全部完美。
3. **响应式测试**：使用 Chrome 开发者工具调整到手机尺寸，验证双栏在窄屏下是否能够顺畅地单栏向下流动，且无任何溢出或变形。
