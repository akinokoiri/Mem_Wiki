如何解决 Infobox 与 MediaCard 的布局排版冲突？

让左侧空白区域得到优雅利用，同时从根源上杜绝元素碰撞和排版错位。

选择你倾向的设计方案
A

(推荐) 现代双栏 Grid/Flex 容器

舍弃脆弱的 float 浮动，将每个物品区块重构为 display: grid 双栏。左侧容纳文字与多媒体，右侧容纳属性面板。高度自动撑开，完美规避 clearfix 且彻底消灭重叠。

B

独立卡片式折叠面板 (Card Wrapper)

基于双栏网格，将每个物品包装在独立的“羊皮纸微晶卡片”内。极具 DST 模组特有仪式感，让左侧的空白转化为艺术性的“呼吸留白”，强化宣传站视觉冲击力。

C

Float 传统流式局部微调

坚持使用 float，但通过将 MediaCard 嵌套到专门的左列盒子中，或者优化 clearfix 对齐时机，强行填补空白。维护成本较高，对移动端响应式不够友好。

方案权衡对比

方案 A 优势

  • 完美排版：MediaCard 与文字纵向流式排列，与右侧 Infobox 并列，彻底填补红框空白。
  • 天然隔离：无需 clearfix，下一个物品天然在下方渲染，绝不冲突。
  • 响应式极佳：在手机端只需一行 CSS 即可自动折叠为单栏。

方案 A 劣势

  • 需要在 CSS 里为物品区块增加简单的 Grid 样式类。
